# AI Video Editing — drop folder

Drop everything for an edit here: footage, audio, images, logos, scripts,
and notes describing the changes you want (e.g. `edit-notes.md`).

Claude (or any agent working on this repo) picks edits up from this folder
and applies them to the HyperFrames project (`index.html`, `compositions/`,
`assets/`).

Suggested layout per edit:

```
ai-video-editing/
  2026-11-08-intro/
    notes.md        # what to change
    clip.mp4        # any media for this edit
```
